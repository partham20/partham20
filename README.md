### What I build

- 🔧 **Firmware** — a permanently-resident 8 KB boot manager for the TMS320F28P55x that can't be bricked, dual-bank CAN-FD OTA across 100+ field boards, 18-channel power metrology with zero-CPU-cycle DMA
- 🐧 **Embedded Linux** — SocketCAN orchestration on i.MX8MP, BACnet stacks, the Makefiles that hold it all together
- 🤖 **With AI, openly** — Claude and Gemini are as much a part of my toolchain as the compiler. I even built my own companion on OpenClaw. Pretending otherwise would be dishonest.

### The fault log

Every real system keeps one. Mine is public — because a version of me without it would be a polished lie.

```c
FAULT_0x01  DEPRESSION      status: RECOVERING   // the long grey. the difference now: it ends.
FAULT_0x02  OCD             status: RECOVERING   // loops still fire; they don't get fed.
FAULT_0x03  ANHEDONIA       status: IMPROVING    // feeling returns in patches. logged.
FAULT_0x04  DPDR            status: STILL_STUCK  // watching life like a movie. working through it.
FAULT_0x05  LIMERENCE       status: DORMANT      // dormant != deleted. i know the difference now.
```

Full service log — meds, therapy, relapses, recoveries — on [the site](https://parthasarathym.com). If you carry your own fault log: keep debugging. Tell someone today.
